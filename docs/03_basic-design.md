### 2. 画面一覧

### 3. 画面ごとの設計

#### TOP
- **画面の目的**: 
  - サイトの概要を紹介する
- **表示する情報**:
  - アニマルフィギュアシリーズの概要（テキスト）
- **使うデータ**:
  - なし
- **主なUI要素**: 
  - 固定：ヘッダー、ナビゲーション
  - メインエリア（サイト紹介テキスト）
- **遷移先**: 商品タイトル一覧

#### 商品タイトル一覧
- **画面の目的**: 
  - 商品タイトルの一覧を表示し、ユーザーが興味のある商品タイトルの詳細に遷移できるようにする。
- **表示する情報**:
  - 商品のリスト（商品タイトル、シリーズ説明文）
- **使うデータ（テーブル一覧、定義参照）**:
    - シリーズ名、シリーズ説明文
    - 商品タイトル名
- **主なUI要素**:
  - 固定：ヘッダー、ナビゲーション、パンくずリスト
  - メインエリア（シリーズごとの商品タイトルリスト）
- **遷移先**: 商品タイトル詳細

#### 商品タイトル詳細
- **画面の目的**: 
  - 商品タイトルの詳細情報を表示し、ユーザーがその商品タイトルに収録されているアニマルの情報を確認できるようにする。 
- **表示する情報**:
  - 商品タイトルの詳細情報（商品タイトル、発売日、収録アニマルの詳細）
  - 中間テーブル(`release_animal`)に「表示順」カラムを設ける予定なので表示順はそれに従う。
- **使うデータ（テーブル一覧、定義参照）**:
    - 商品タイトル名
    - 発売日
    - 収録アニマルの名前（商品タイトルごとに複数あるため、テーブル結合で取得する想定） 
- **主なUI要素**:
  - 固定：ヘッダー、ナビゲーション、パンくずリスト
  - メインエリア（商品タイトルの詳細情報）  
  商品タイトルの詳細情報には、商品タイトル名、発売日、収録アニマルの名前と画像を表示する想定。  
- **遷移先**: なし（TOPや商品タイトル一覧へはナビゲーションから遷移可能）  
今後アニマルごとの詳細ページを作成する可能性がある（アニマル詳細ページの新設は将来拡張とする）

#### 検索
- **画面の目的**:
  - アニマル名で横断検索を行い、そのアニマルが収録されているタイトル一覧を表示する。
- **表示する情報**:
  - 検索ワードにヒットしたアニマル名、収録タイトル名
- **使うデータ**:
  - animal.name、animal.species_name（両方で検索）、release.name
- **主なUI要素**:
  - SearchForm（ヒーダーに常時表示）
  - 検索結果テーブル（アニマル名、収録タイトル名、収録種別）
- **遷移先**: 商品タイトル詳細

### 8. データ取得・更新方針

- 商品タイトル一覧取得は `release` を基点に取得する
- 商品タイトル詳細取得は `release` を基点に、`release_animal`、`animal`、`release_image` を組み合わせて取得する
- 検索は `release_animal` を基点に `animal.name` / `animal.species_name` でフィルタリングする
- 現在、Prisma Client は `page.tsx` から直接履用している（将来的にデータアクセス層へ集約予定）

#### Prisma の利用方針
- `lib/prisma.ts` で PrismaClient シングルトンを定義し、`@prisma/adapter-pg` 経由で PostgreSQL に接続する
- 現在は各 `page.tsx` から直接呼び出す構成だが、将来的に `lib/` 配下のデータアクセス層へ集約予定

#### 将来のバックエンド切り出しを見据えた方針
- 初版では Next.js アプリ内でデータ取得・更新を完結させる
- 将来的に API 経由の構成へ移行する場合は、データアクセス層の実装を Prisma から外部 API 呼び出しへ差し替えるのが目標

### 9. 画像管理方針
画像ファイルは `public/images/releases/{id}/` 配下に手動配置する。  
`release_image` テーブルで画像パスと表示順を管理し、ImageGallery コンポーネントで表示する。

### 10. エラー時の扱い

- データ取得失敗
  - 「データが取得できませんでした」と表示する

- 商品タイトル一覧が0件の場合
  - 「現在表示できる商品タイトルはありません」と表示する

- 指定した商品タイトルが存在しない場合
  - 「対象の商品タイトルが見つかりませんでした」と表示する

- 画像がない場合
  - 「NO IMAGE」の画像を表示する

- 画面全体のエラー
  - 「エラーが発生しました。時間を置いて再度お試しください」と表示する
