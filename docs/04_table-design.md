# テーブル設計メモ
※ 実際のテーブル定義は Prisma スキーマファイル（`prisma/schema.prisma`）を参照してください。

## 前提
このサイトでは、以下のような構造を扱いたい。

- 1つのタイトルには複数のアニマルが収録される
- 1匹のアニマルは複数のタイトルに収録されうる
- さらに、「どのタイトルに収録されたどのアニマルか」という単位で、画像や備考などの情報を持たせたくなる可能性が高い

例:
- ライオンは複数タイトルに収録されている
- 同じライオンでも、タイトルごとに画像や補足情報を持たせたいことがある

このため、`animal` と `release` を直接つなぐのではなく、中間テーブルを用いる構成を採用する。

---

## テーブルの役割

## 1. animal（アニマルマスタ）
アニマルそのものの情報を管理するテーブル。

### 持たせる情報の例
- アニマルID
- 名前
- 図鑑番号
- 世代
- タイプ
- 備考

### このテーブルの意味
ここには「アニマル自体に属する情報」を持たせる。  
商品タイトルに依存しない、アニマル固有の情報を管理するためのマスタ。

たとえば、ライオンという存在自体は1件として管理する。  
ライオンが複数タイトルに登場しても、`animal` に同じライオンを何件も作らない。

---

## 2. release（タイトルマスタ）
商品タイトルそのものの情報を管理するテーブル。

### 持たせる情報の例
- タイトルID
- タイトル名
- 発売時期
- シリーズ区分
- 備考

### このテーブルの意味
ここには「商品タイトルそのものに属する情報」を持たせる。  
アニマルフィギュアシリーズ Vol.1、アニマルフィギュアシリーズ Vol.2、金銀編の各タイトルなどを管理するためのマスタ。

---

## 3. release_animal（中間テーブル）
「どのタイトルに、どのアニマルが収録されているか」を表すテーブル。

### 持たせる情報の基本
- ID
- release_id
- animal_id

これによって、`release` と `animal` の多対多の関係を表現できる。  

プラスで、以下のような情報も持たせることができる。
- 表示順
- その商品におけるメモ
- 入手難易度（出回り感）
- カラーバリエーション

### 例
- アニマルフィギュアシリーズ Vol.1 に ライオン が収録されている
- アニマルフィギュアシリーズ Vol.1 に ゾウ が収録されている
- アニマルフィギュアシリーズ Vol.2 に ライオン が収録されている

このような関係を表現するために必要。

---

## なぜ中間テーブルが必要か
今回の題材では、以下のような関係になる。

- 1つのタイトルには複数のアニマルが入る
- 1匹のアニマルは複数のタイトルに入る

つまり、`release` と `animal` は多対多の関係になる。

多対多は、そのままでは素直に表現しづらいため、両者の間に中間テーブルを置いて解消する。

これにより、たとえばライオンが複数タイトルに収録されていても、`animal` にはライオンを1件だけ持ち、`release_animal` 側に複数行を持たせることで表現できる。

### イメージ

```text
animal
- 1: ライオン

release
- 1: アニマルフィギュアシリーズ Vol.1
- 2: アニマルフィギュアシリーズ Vol.2
- 3: アニマルフィギュアシリーズ金銀1

release_animal
- release_id=1, animal_id=1
- release_id=2, animal_id=1
- release_id=3, animal_id=1

---

## 再録の表現方法

タイトルによっては、過去タイトルのアニマルを再録（再収録）することがある。  
例: アニマルフィギュアシリーズ4 はアニマルフィギュアシリーズ Vol.3 のアニマル6体を再録している。

再録を表現するために、`release_animal` テーブルに `reprint_from_release_id` カラムを持たせる。  
これは同じ `release` テーブルを参照する自己参照的な外部キーとなる。

| 状況           | `reprint_from_release_id` の値      |
|---------------|-------------------------------------|
| 新規収録        | NULL                                |
| 再録           | 再録元タイトルの `release.id`         |

### イメージ

```text
release
- 3: アニマルフィギュアシリーズ Vol.3
- 4: アニマルフィギュアシリーズ4

animal
- 7: ゼニガメ

release_animal
- release_id=3, animal_id=7, reprint_from_release_id=NULL  ← MC3 に新規収録
- release_id=4, animal_id=7, reprint_from_release_id=3     ← MC4 は MC3 からの再録
```

### なぜ `release_animal` 側に持たせるか

「同じアニマルでもタイトルによって再録かどうかが変わる」ため、  
アニマル自体（`animal`）やタイトル（`release`）ではなく、  
その組み合わせを表す `release_animal` 側に持たせるのが適切。
